Reproducibility repository for:

> Kass, N.A., Kass, C.A., Tettamanti, G., Kacoliris, F.P., and Williams, J.D.
> **Field-based morphometric characterization and size distribution of a
> Laguna Azul population of *Atelognathus reverberii* (Cei, 1969),
> Somuncurá Plateau, Patagonia.**
> Submitted to *Ichthyology & Herpetology*.

All figures, tables, statistics, and reportable quantities cited in the
paper are produced by running `scripts/morfometria.py` on the dataset in
`data/`. Results match the published values to rounding precision.

---

## What this repository contains

A single Python script reproduces the entire analysis pipeline of the
paper from field-collected morphometric data on 274 measured
individuals (out of 275 marked individuals) at Laguna Azul,
Somuncurá Plateau, Patagonia, during the 2019–2020 austral
spring–summer.

The analyses include:

1. **Descriptive morphometrics** (Table 1): means, SDs, ranges, and
   bootstrap 95% confidence intervals by sex/age class.
2. **Sexual dimorphism tests** (Table 2): two-sided Mann–Whitney *U*
   with Cohen's *d* effect size and Shapiro–Wilk normality.
3. **Statistical power analysis**: asymptotic-relative-efficiency (ARE)
   correction for Mann–Whitney power under normal-equivalent data;
   acknowledged as a lower bound under the observed non-normality of
   body mass.
4. **Misclassification sensitivity** (Buonaccorsi 2010 linear
   correction): symmetric threshold plus a direction-aware asymmetric
   scenario (30% female→male, 5% male→female).
5. **Size distribution** (Figure 1, Figure 2): Gaussian Mixture Model
   selection by BIC over *k* = 1–5 with a bootstrapped likelihood-ratio
   test for unimodality (McLachlan 1987); bootstrap CIs on *k* = 2
   component parameters (descriptive only).
6. **Length–weight allometry** (Table 3, Figure 4): log-log OLS
   regression, formally tested against two-dimensional (*b* = 2) and
   three-dimensional (*b* = 3) isometric expectations, by sex/age class
   and pooled.
7. **Body condition** (Figure 5): residuals from a reference regression
   fitted exclusively to undetermined-sex adults (sex-neutral baseline
   per Green 2001), tested by Kruskal–Wallis with Bonferroni-corrected
   pairwise comparisons. Includes a **sensitivity check** under an
   alternative (pooled) reference slope to test robustness of the
   surviving juvenile–male contrast.
8. **Comparison with the type series**: the present sample is contrasted
   with the seven-specimen description of Cei (1969).


## Running the analysis

```bash
python scripts/morfometria.py
```

That single command reproduces all figures and tables in `outputs/`,
plus `reportable_quantities.json` (a flat JSON file containing every
numeric value cited in the manuscript). Typical run time on a laptop is
about 1 minute, dominated by the bootstrapped likelihood-ratio test
(*B* = 999 replicates) and the *k* = 2 GMM bootstrap (*B* = 500).

All random number streams use fixed seeds (`seed = 42`) so the output is
deterministic across runs.

## Key results

- **No detectable sexual size dimorphism** in any of three variables
  (Mann–Whitney *U*, all *p* > 0.34; Cohen's |*d*| < 0.09 in all
  variables; statistical power = 74.7% for *d* = 0.5, exceeding 80% for
  *d* ≥ 0.53 under the normal-theory ARE).
- **Unimodal size distribution** of the detected sample (BIC selects
  *k* = 1; bootstrapped LRT *p* = 1.00).
- **Length–weight allometry**: pooled *b* = 1.97 (95% CI 1.79–2.15),
  consistent with two-dimensional isometry as an upper bound but not
  excluding modest hypoallometry; juveniles separately *b* = 2.53,
  significantly above 2 and below 3.
- **Body condition**: Kruskal–Wallis *H* = 6.25, *p* = 0.044, *η²* =
  0.029 ("small" effect). A juvenile–male contrast was significant
  under the reference-slope baseline (Bonferroni-corrected *p* = 0.025)
  but **did not survive a sensitivity check** under an alternative
  (pooled) reference slope (*p* = 0.209) and is reported as a hypothesis
  to be tested in larger samples.
- **Misclassification robustness** (Buonaccorsi linear correction): the
  null dimorphism result holds for any plausible level of field
  sex-assignment error; the symmetric threshold for an effect of |*d*|
  ≥ 0.2 is *p* ≈ 39.6%, and a direction-aware asymmetric scenario
  (30% female→male, 5% male→female) leaves the corrected effect within
  the negligible range.

## Comparison with the original description

| Measure                  | Cei (1969), n = 7    | This study, n = 274  |
|--------------------------|----------------------|----------------------|
| Sample size              | 7 (5 ♂, 2 ♀)         | 274                  |
| Locality                 | L. Raimunda + Miñuelo | Laguna Azul         |
| Measurement              | SVL (to cloaca)      | SUL (to urostyle)    |
| Male size                | 35–38 mm SVL         | 23.3–35.9 mm SUL     |
| Female size              | 36.5–38 mm SVL       | 21.2–38.8 mm SUL     |

SVL (to cloaca) is systematically longer than SUL (to urostyle) by a
taxon-specific offset not yet calibrated for *A. reverberii*. The two
measurements are reported here for order-of-magnitude context only and
are not interconverted.

## Reproducibility notes

- **Determinism.** All stochastic procedures use fixed seeds:
  - Bootstrap CIs for descriptive statistics: `seed = 42`, *B* = 2,000.
  - Bootstrapped LRT (McLachlan 1987): `seed = 42`, *B* = 999.
  - *k* = 2 component bootstrap CIs: `seed = 42`, *B* = 500.
  - Misclassification correction bisection: deterministic.
- **Software versions** are pinned in `requirements.txt` and tested on
  Python 3.11.x and 3.12.x with NumPy ≥ 1.26, SciPy ≥ 1.11,
  scikit-learn ≥ 1.3, and pandas ≥ 2.1.
- **Provenance.** The dataset has not been modified since the original
  field-collection step; all cleaning is performed in
  `scripts/morfometria.py` at load time (sex-label normalisation,
  missing-value filtering).
